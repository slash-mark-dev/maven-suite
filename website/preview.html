Maven Suite

Java Package Intelligence Suite. Explore, analyze, and manage Maven artifacts with our specialized toolset, on live data, in real time.

jbang app install --name sm-maven in.slashmark:maven-suite:1.0.0

or download the JAR and run java -jar maven-suite-1.0.0.jar help

  • 25 tools · one command
  • Live: Maven Central, OSV, CISA KEV, EPSS, deps.dev, GitHub
  • Watch mode + Slack/Teams/Discord/e-mail alerts
  • Maven-exact resolution
  • JSON output & CI exit codes
  • Java 17+ · zero dependencies · MIT

01ThreatLIVE

Live CVE Watch

Watches your whole dependency tree and alerts the moment a new advisory affects it.

$sm-maven cve-watch --watch --interval 15m
02Threat

Zero-Day Impact Scanner

Enter a CVE and see every affected path in every module, plus the smallest fix.

$sm-maven impact CVE-2021-44228
03Threat

Exploit Prioritizer

Ranks vulnerabilities by live CISA KEV status and EPSS exploit probability, not just CVSS.

$sm-maven prioritize --top 10
04ThreatLIVE

Malicious Release Guard

Flags risky new releases: changed signing key, new Java agents, native code, process execution.

$sm-maven release-guard
05ThreatLIVE

Namespace Takeover Watch

$sm-maven takeover --group com.example

$sm-maven pulse --transitive
